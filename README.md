# Portfólio | Nathalia Barbosa — Psicóloga

Projeto de desenvolvimento web para a psicóloga Nathalia Barbosa, criado com o objetivo de apresentar sua trajetória profissional, áreas de atuação e abordagem de trabalho por meio de uma experiência digital moderna, acolhedora e intuitiva.

O design foi pensado para transmitir confiança, profissionalismo e acolhimento, alinhando a identidade visual do site à proposta de atendimento psicológico.

## ✨ Funcionalidades

- Apresentação profissional da psicóloga.
- Seção sobre sua trajetória e experiência.
- Exibição das áreas de atuação e dos serviços oferecidos.
- Apresentação da abordagem de trabalho.
- Seção de contato para facilitar a comunicação.
- Layout responsivo para diferentes tamanhos de tela.
- Identidade visual personalizada.

## 🛠️ Tecnologias utilizadas

- **React:** construção da interface por meio de componentes.
- **TypeScript:** tipagem estática para maior organização e segurança no desenvolvimento.
- **Vite:** ambiente de desenvolvimento e ferramenta de build.
- **CSS3:** estilização, layout, responsividade e detalhes visuais.

## 🎨 Design e experiência

O projeto utiliza uma identidade visual desenvolvida para transmitir leveza, equilíbrio e acolhimento.

A organização das seções, a tipografia, as cores e os elementos visuais foram pensados para proporcionar uma navegação clara e uma apresentação profissional.

## 🚀 Como executar o projeto

### Pré-requisitos

- Node.js instalado.
- npm disponível no ambiente.

### Instalação

Clone o repositório e acesse a pasta do projeto:

```bash
git clone [https://github.com/camillaalvess/portf-lio-psicologia.git]
cd portfólio-psicologia
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

O Vite exibirá no terminal o endereço local para acessar o projeto pelo navegador.
